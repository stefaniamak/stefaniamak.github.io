# Stefania Makrygiannaki - Personal Portfolio Website

A fully responsive personal website for a Senior Flutter Software Engineer, built with vanilla HTML, CSS, and JavaScript.

## Features

- **Fully Responsive**: Optimized for mobile, tablet, and desktop screens
- **Three Theme Modes**: Light, Dark, and System (defaults to system preference)
- **Work Experience Accordion**: Expandable/collapsible experience items
- **Project Showcase**: Filterable project grid with detailed modal views
- **Clean, Minimal Design**: Editorial-leaning aesthetic with black/white/gray palette
- **Accessible**: Semantic HTML, keyboard navigation, proper ARIA labels
- **Typography**: Uses Jacquarda Bastarda for display text and Roboto Slab for body text

## File Structure

```
stefania-portfolio/
├── index.html      # Main HTML structure
├── styles.css      # All styling and responsive design
├── script.js       # Interactive functionality
└── README.md       # This file
```

## Getting Started

Simply open `index.html` in a web browser. No build process or dependencies required.

## Customization

### Update Contact Information
Edit the contact links in `index.html` (lines 177-197) with your actual URLs and email.

### Update Work Experience
Modify the work experience items in `index.html` (lines 50-115) with your actual experience.

### Update Projects
Edit the `projectsData` array in `script.js` (lines 2-70) to add or modify your projects.

### Update Personal Information
Modify the hero section in `index.html` (lines 30-46) with your personal introduction.

## Browser Support

Works in all modern browsers that support:
- CSS Grid
- CSS Custom Properties (CSS Variables)
- ES6 JavaScript
- localStorage API
